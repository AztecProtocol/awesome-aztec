# Contribution Guidelines

## Adding Links

Propose link additions by visiting [README.md](./README.md) and click the "pen" icon in the top right corner. Make changes to the file and follow the instructions to create a pull request.

## Entry policy

- **Official links stay in one place.** Official Resources lists Aztec's main entry points (site, docs, forum, repositories), and Talks and workshops can include Aztec's own courses. Everything else is third-party: if the [docs](https://docs.aztec.network/) already cover it (official example repos, docs pages), link the docs instead of adding it here.
- **State the Aztec version.** Label code entries with the Aztec major version their default branch depends on, for example `v6`: the `@aztec-labs/*` or `@aztec/*` version in `package.json`, or the aztec-nr tag in `Nargo.toml`. Articles, talks and tools with no Aztec dependency take no label.
- **Stay current.** Entries more than one major version behind the current release (v6 today) get removed.
